# Background Generator

A simple web app that generates beautiful random CSS gradient backgrounds instantly.

# Live Demo
[Click here to view the live site] https://yukay2907.github.io/Background_Colour_Generator/

# Features
- Pick two colors using color pickers
- Generates a live CSS gradient background
- Displays the CSS code you can copy and use
- Generate random gradients with one click

# Built With
- HTML
- CSS
- JavaScript

# How to Use
1. Pick two colors using the color pickers
2. The background updates instantly
3. Copy the CSS code shown on screen
4. Click **Generate Random Gradient** for a random combo
